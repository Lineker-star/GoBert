# Sécurité

GoBert s'engage pour votre sécurité :

- Chaque prestataire est vérifié (CNI, permis, carte grise) avant d'être approuvé.
- Les plaques d'immatriculation sont affichées pour identifier le véhicule.
- En cas d'urgence, utilisez le bouton SOS dans l'application.
- Les paiements se font en espèces, à bord, sans manipulation d'argent en ligne.
- Pour signaler un problème, contactez le support via l'assistant ou la page « Parler à un humain ».

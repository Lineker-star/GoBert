# Tarifs GoBert

Les tarifs sont calculés selon la distance et la durée, en Francs CFA (XAF) :

- **Moto** : base 300 XAF + 100 XAF/km.
- **Taxi** : base 500 XAF + 150 XAF/km.
- **Tricycle** : base 400 XAF + 120 XAF/km.
- **Camion** : base 1000 XAF + 300 XAF/km.
- **Location** : dès 2500 XAF/heure ou 12000 XAF/jour, caution demandée.

Le tarif minimum par course est de 500 XAF. Aucun frais caché : le prix affiché avant confirmation est le prix final (hors pourboire).

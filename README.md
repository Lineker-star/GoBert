# GoBert

Mobility platform for Bertoua and the East, Adamawa, North and Far North regions of Cameroon. Tagline: "Move. Connect. Go."

## Local setup

1. Install Node 20+, pnpm 9, Supabase CLI.
2. `pnpm install`
3. Copy `.env.example` to `apps/web/.env.local` and fill values.
4. `pnpm dev` (web on :3000, admin on :3001).
